# Add SHA-512 for the offline Ed25519 fallback

W21 requires a pure JavaScript fallback for Ed25519 verification. The frozen
`@noble/ed25519@3.2.0` verifier needs a SHA-512 implementation. Its default
asynchronous hash delegates to SubtleCrypto, which would prevent verification
when WebCrypto is entirely absent.

Add `@noble/hashes@2.0.1` as an exact, additive W00 dependency. Retain the
existing Ed25519 version. The registry tarball SHA-256 is
`638ffb3053a7e7478c9e54a6e297f3601299ee570a41112e501af7050d086a0a`;
SHA-512 SRI is recorded in the dependency and npm locks. Its MIT license is
retained in the package. Ship only the SHA-2 module and its three relative
dependencies, without Node imports or a CDN. Every emitted asset receives a
package SHA-256 entry. The fallback uses strict Ed25519 verification.

Validation includes the native development issuer's signed fixtures, corrupt
signatures, a test with all WebCrypto disabled, browser offline execution and
an installed-tarball CSP test. The fallback grants client API access only;
server entitlements are outside this mechanism.
