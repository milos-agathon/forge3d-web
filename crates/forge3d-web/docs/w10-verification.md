## Native scene acceptance

`tests/playwright/w10_native.spec.ts` reconstructs native test scenes through
the real web scene/runtime API. The references in `tests/golden/w10/native/`
are generated by installed native forge3d, never by a browser capture. The
same web frames are also compared against the historical native PNGs at
`1f4084a:tests/golden/terrain/terrain_{water,water_reflection,atmosphere}.png`.
All comparisons require SSIM >=0.98; disabled clouds/water must fail it.

| Scene | Installed-native SSIM | Historical SSIM | Disabled control SSIM |
|---|---:|---:|---:|
| Baseline terrain | 0.999548 | n/a | n/a |
| Atmosphere/aerial | 0.998647 | 0.998647 | covered-pixel controls below |
| Masked terrain water | 0.999281 | 0.999281 | 0.865832 |
| Water-reflection fixture | 0.999475 | 0.999475 | 0.784951 |
| Native cloud quad | 0.999783 | n/a | 0.961629 |

Terrain references use an isolated installed wheel built from pinned native
`bf8db93233e5158f6d226991fc5d230832c2d806` (version 1.26.0). Native 1.34/1.40
produce different atmospheric images, so they are not interchangeable oracles
for this source baseline. The pinned cloud shader has invalid WGSL semicolon
struct fields; its public Scene cloud render cannot execute. The cloud oracle
therefore uses a separately installed forge3d 1.34.0 Scene renderer. The
manifest records each version, the pinned wheel hash, cloud extension hash,
scene source digest and image hashes. No native arithmetic is patched.

The reflection fixture's SSIM chiefly measures masked-water shading. It does
not establish every native masked-terrain planar-reflection scenario. Mirrored
scene reflections belong to explicit water layers in this port; their enabled
vs sky-only behavior is tested separately. Native clouds use a clip-space quad;
the default depth-clipped world cloud path remains a documented approximation.
Native-path cloud IBL uses the native default tint, not arbitrary scene IBL.

## Recorded behavioral contracts

- `sun-vector-v1` in `tests/golden/w10/sun.json`: 48 independent native cases,
  angular error <=5e-9 degrees and direction component error <=1e-6, with the
  native Y-up/east-minus-X/north-minus-Z convention. The fixture generator and
  committed unit test both use this contract.
- All six aerial controls change 13,336 covered terrain pixels: mean RGB byte
  differences for turbidity, ground albedo, sky sun intensity, sun size,
  exposure and density are 43.91, 5.78, 26.31, 8.78, 17.80 and 3.27. Disabled
  aerial perspective and density zero each restore covered pixels exactly.
- A rendered London sunrise at 2024-06-21 04:00 UTC (elevation 1.245 degrees)
  differs from noon by 33.12 mean covered RGB bytes and repeats exactly.
- `volume-temporal-v1.json` runs at 1920x1080, bounds [-8,0,-8,8,12,8], with
  8x6x8 localized-haze density, 32 steps, full resolution and temporal weight
  0.8. History is valid after repeated renders. There are 158,318 contributing
  inside pixels and zero changed bytes across 1,878,324 outside pixels, checked
  against independent CPU ray/box intersections; the limit is one byte.
- `w09-preservation.json` comes from an independent `git archive` export and
  WASM build of main 7b738f9. No environment preserves display and HDR SHA-256
  exactly for terrain/material/ground and scatter/probes scenes. Both frames
  require more than 1,000 covered pixels. The committed browser test checks it.
- Fog defaults are native uniform, phase g=0, shafts off and falloff 0.1;
  anisotropy accepts [-1,1]. Sky-driven fog and aerial composition, water
  Fresnel/tint/ripple/refraction/shore/distortion controls, native cloud modes
  and preset animation speed are exposed through TS and Rust validation.

Source/dist, worker, HDR capture, loss replay, atomic budgets, resize, half-res,
froxels, shadow occlusion, foam/masks and 16-texture devices remain covered.
Browser sky/cloud/water RGBA regressions remain separate from native references;
they were refreshed for the intentional aerial/default changes and then checked
without capture enabled. Native sky/cloud/wave arithmetic probes are supplemental.

## Regeneration

Export the pinned native source with `git archive --format=zip --output=...`,
extract into a scratch directory, and run `maturin build --release --out ...`
with a separate CARGO_TARGET_DIR. Install the resulting 1.26.0 wheel with
`python -m pip install --no-deps --target <isolated-native-directory> <wheel>`.
Install forge3d 1.34.0 into another isolated directory for the cloud reference.
Keep the user's current native installation unchanged.

Run `scripts/generate-w10-render-goldens.py` with PYTHONPATH selecting 1.26.0,
W10_NATIVE_WHEEL naming its wheel and W10_NATIVE_CLOUD_PATH selecting the
isolated 1.34.0 directory. The script executes the original native scene
helpers, asserts repeat renders are byte-identical and retains historical
images verbatim. Native regeneration repeats the recorded hashes.

For W09 preservation, build an independent 7b738f9 archive with a separate
target directory. Copy `test-w10.html`, `w10-acceptance.js`,
`w10-native-probes.js` and `test-w10-worker.js` into its examples directory,
serve with Vite, then run `node scripts/generate-w10-w09-preservation.mjs
http://127.0.0.1:<baseline-port>` from this package. The generator uses the
baseline runtime rather than the W10 runtime.
