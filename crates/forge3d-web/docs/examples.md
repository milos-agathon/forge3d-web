# Native example migrations

All 54 final example assets have an explicit browser workflow. The consolidated gallery runs every distinct workflow and reports which results each original example consumes. It uses bounded offline inputs; it does not download or recreate regional Python, GIS, transport, climate or video-production datasets. The historical source remains linked for those application-specific pipelines.

[Open the runnable gallery](../examples/migration/index.html). Serve the installed package over HTTP on localhost or HTTPS.
